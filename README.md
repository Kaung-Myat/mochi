# Mochi

A gentle, private health-routine companion PWA. See [PRD.md](./PRD.md) for requirements and [IMPLEMENTATION_PLAN.md](./IMPLEMENTATION_PLAN.md) for delivery phases.

## Foundation and Phase 1 status

The Next.js app shell, TypeScript/Tailwind foundation, Firebase Emulator configuration, environment template, and architecture decisions are present. Phase 1 adds protected routes, Google and email/password sign-in UI, onboarding progress saved on-device, profile persistence, and owner-only profile rules. See [docs/development.md](./docs/development.md) for setup and verification.
